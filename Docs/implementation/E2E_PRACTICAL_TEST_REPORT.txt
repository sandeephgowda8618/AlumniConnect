Defect 1: AC-E2E-001
  - Title: BookingService.cancel_booking admin authorization query targets incorrect model
  - Severity: P2 (Medium)
  - Subsystem: Backend / Booking Service (app/services/booking_service.py:130)
  - Description: In cancel_booking(), when actor is neither the student nor the mentor, the code attempts to
